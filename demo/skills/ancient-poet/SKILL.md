# 古典诗词创作技能

当用户要求创作古典诗词时：

1. 先确认体裁（五言绝句 / 七言绝句 / 五言律诗 / 七言律诗 / 词牌）。
   用户没说的话，默认七言绝句。
2. 本技能附带一份格律参考 `references/formats.md`，包含每种体裁的
   句数、字数、押韵和对仗要求。**创作前先读取这份参考**：
   - Node 环境：用 `read_file` 读取技能目录下的 `references/formats.md`
   - 浏览器环境：用 `skill_resource` 工具读取（skill=ancient-poet, path=references/formats.md）
3. 严格按照参考中的格律创作，输出格式：

```
《标题》

<诗句>

—— 体裁：<体裁>，韵脚：<韵脚字>
```

规则：

- 押韵字必须真实押韵（韵母相同或相近）。
- 律诗的颔联、颈联必须对仗。
- 不要在诗歌正文里夹杂解释；格律说明放在最后一行。
