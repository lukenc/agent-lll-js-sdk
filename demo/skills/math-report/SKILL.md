# 计算报告技能

当用户需要一份"计算报告"时，按以下流程执行：

1. **拆解**：把用户的问题拆成一个或多个独立的数学表达式。
2. **计算**：逐个调用 `calculate` 工具求值，不要心算。
3. **汇报**：将结果整理成如下 Markdown 格式的报告：

```
## 📊 计算报告

| # | 表达式 | 结果 |
|---|--------|------|
| 1 | <表达式> | <结果> |

**结论**：<用一句话总结所有结果的含义>
```

规则：

- 每个表达式必须真实调用过 `calculate` 工具，禁止直接编造结果。
- 结果保留合理精度（默认 4 位小数，整数不带小数点）。
- 如果用户的问题里有单位，结论中必须带上单位。
